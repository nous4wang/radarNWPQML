## 1. 结论先行

科学层面：不建议把这份蓝图推进为 CVPR / ICML 主会路线。它把三类已被上游
零算力 gate review 判负并封口的机制重新包装为「希尔伯特升维线性化 / 密度矩阵
归因 / 保范围极值放大」，但没有提供任何新的机制证据。§11.8.2 的规则是
「被证否 = 停止派生，**不是换个说法再试一次**」（`MASTER.md:1456`），
本蓝图正属于后者。

工程层面：`§5` 的四段 PyTorch 代码**不能直接运行**，也不能接入上游训练/评测。
§4 列出 **25 条编号缺陷**（D1–D5、S1–S6、T1–T5、P1–P5、G1–G4）。
经 ARIS W2 Round 1 复审，**S1 与 T2 为硬误报，已撤回**（见 §1.1），
成立 23 条。最硬的工程阻断仍是 **T1：CFM 分支没有训练目标**，
ODE 输出是未训练的随机场。

但可以拆开看：蓝图在**数据侧**提出的几个问题（多帧累积与单帧的配准相关性阶梯、
静态地理/极坐标先验、`3×3` 无损折叠的吞吐基准、未来时次有效掩码协议）本身是
可验证、未被封口的工程问题。它们与「实现 QLFN 模型」是两件事，值得作为独立
数据审计管线保留（见 §5）。

因此本轮决策：
1. QLFN 代码库按用户指定命名落地，修掉可修的工程缺陷，补齐 CFM 训练目标；
2. 所有物理声称在代码 docstring 中**降级为诊断量**，不写「严格等价 / 解析物理探针」；
3. 文件头显式标注与 §11.8.2 的冲突，不启动训练、不改上游、不写入
   `configs/baselines.json` 或任何权威表；
4. 研究建议本身标记为 BLOCKED，保留为反面案例与工程练习。

### 1.1 复审更正（ARIS W2 Round 1，2026-11-08）

审查者给出 `5 / 10`、结论 `BLOCKED + provisional`。其最硬的两条反对意见是
本评审把两处**不存在的缺陷**写成了「已修」，并据此把「修好了」当作工程
合理性的证据。核对蓝图原文后，两条均成立，正式撤回：

**旧 S1（撤回，硬误报）。** 本评审原称 `z_extreme_101` 是 `(B,96,101,101)`、
`decode` 期望 90 通道、`view(-1,9,H,W)` 在 96/9 非整数下必然抛错。
核对蓝图 §5.4 `LatentConditionalFlowHead.__init__`：
`self.out_ch = t_out * 9  # 对应 10 帧 × (3×3 子像素)`，即 **90 通道**；
`integrate_ode` 返回的 `z` 也由 `self.out_ch` 定形。于是
`view(-1,9,H_c,W_c)` 得到 `(B*10,9,H_c,W_c)`，`PixelShuffle` 还原
`(B*10,1,303,303)`，裁成 301 后 `view(B,-1,1,301,301)` 完全合法。
`nn.Identity()` 在这里只是把已经 90 通道的 ODE 输出直接交给解码器，
**不会 shape 崩**。真正的问题另有所指：极值分支没有独立的解码 head，
且 T1 使 `velocity_net` 从未被训练；此外 `decode` 对通道数没有断言（S5）。
QLFN 里「Fixed S1 / 禁止 `nn.Identity()`」的表述属于把误报固化，
已在代码与规格中改为「S5 通道断言 + T1 训练目标」。

**旧 T2（撤回，硬误报）。** 本评审原称蓝图 `fp = Σ p_hit(1−t_hit)`、
`fn = Σ(1−p_hit)t_hit` 会在缺失帧把 `1−t_hit=1` 当负样本。
核对蓝图 §5.4 第 799–803 行：`p_hit = sigmoid(...) * mask`、
`t_hit = (...) * mask` 已先乘掩码。令 `m∈{0,1}`、`t∈{0,1}`、`p∈[0,1]`，
记 `p'=pm`、`t'=tm`，因 `m²=m`：

| 项 | 蓝图原式 | QLFN 改写式 | 是否等价 |
|---|---|---|---|
| `tp` | `p't' = ptm` | `p_m t_m = ptm` | 等价 |
| `fp` | `p'(1−t') = pm − ptm = pm(1−t)` | `p_m(m−t_m) = pm(1−t)` | 等价 |
| `fn` | `(1−p')t' = tm − ptm = tm(1−p)` | `(m−p_m)t_m = tm(1−p)` | 等价 |

缺失帧 `m=0` 时蓝图三式全为 0，**没有虚假计数**。QLFN 的
`masked_contingency` / `masked_contingency_torch` 只是等价重写，
不是缺陷修复；其真实价值是补上「掩码必须是 0/1」的契约与全掩码回归测试
（两式仅在 binary mask 下等价，软掩码下不等价）。§4.3 T2、
`02-engineering-audit.md`、`losses.py` / `data_audit.py` 文件头、
`QLFN_SPEC.md` R8 与两处自检脚本已同步更正。

**其余同步更正：** ① §3.1 关于 `docs/SPEC.md:37` 的「建议修正 SPEC N4」
是稻草人，已重写；② §2 显式评估 §11.8.2「原对照不成立」例外分支；
③ D2/D4 措辞收窄（301 是打分全场而非模型输入，但 `MASTER.md:1556`
给出的格距是 **1.11195 km/px**，不是蓝图与 QLFN 隐含的 1 km/px）；
④ 「15 项」为计数错误，实为 25 条编号、23 条成立。

|---|---|---|
| T1 | §5.4 `LatentConditionalFlowHead` + §5.4 loss | **CFM 没有训练目标**（本轮最硬缺陷）：只有 `forward_velocity` 与 `integrate_ode`，损失函数里没有 `‖v_θ(z_s,s,c) − (x₁−z₀)‖²`。ODE 输出是未训练的随机场；`deterministic_eval=True` 从零起点积分只保证可复现，不保证学到分布。另：训练若用 `randn` 先验而推理用 zero prior，会造成先验不一致，QLFN 的初版「补 T1」就引入了这一新问题（见 §6） |
| ~~T2~~ | §5.4 `compute_masked_coverage_extreme_loss` | **已撤回（硬误报）**：蓝图 `p_hit`/`t_hit` 已先乘 `mask`，`fp = Σ p_hit(1−t_hit)` 与 `fp = Σ p_m(m−t_m)` 对 binary mask 代数等价（推导见 §1.1），缺失帧不产生虚假计数。QLFN 的改写只是等价重写；真正该补的是「mask 必须为 0/1」的契约、全掩码回归测试，以及软掩码下两式不等价的说明 |
| T3 | §5.4 保范围合成 | `wet_mask = sigmoid((R_body−0.25)*12)` 是软掩码，阈值 0.25 与 0.5 不一致；叠加正残差会把 0.4–0.5 边界像素推过 0.5，**列联表计数与 BIAS@0.5 必然改变**。蓝图「从数学结构上保证 0.1/0.5 范围不变」不成立 |
| T4 | §5.4 `soft_csi` | 用 sigmoid 软命中近似硬 CSI，与权威表 `CSI@2.0` 口径不同，不能用来宣称「CSI 不退化」；`loss_csi = torch.tensor(0.0)` 每步重建亦低效 |
| T5 | §3 Step 4 判据 | 「10-seed 两级 Bootstrap 显著超越」与本项目已实测的「固定 seed bit-exact 确定性」冲突：没有独立抽样时，重采样区间只描述 seed 集合敏感性，不是置信区间（`analyze_seed_sensitivity.py` 已固化） |

### 4.4 物理声称与实现脱节

| ID | 位置 | 问题 |
|---|---|---|
| P1 | 定理 1 | Stone-Weierstrass 只保证三角多项式基可一致逼近紧集上连续函数；rank-M 谱投影是**近似**且无误差界，不能写「严格等价」「线性复杂度精确压缩」 |
| P2 | §5.3 `QuantumHilbertLatentInteraction` | 全程没有构造 ρ_RN、没有偏迹、没有 Schmidt/SVD。`prob_k` 是两个 1×1 卷积输出乘积的归一化，不是约化密度矩阵本征谱；`S_vN` 因此不是物理纠缠熵 |
| P3 | 命题 2 | 「当且仅当强耦合时 S_vN 极大」不成立：vN 熵在谱均匀/最大混合时最大，与「强非线性锁相」无必然联系；且「Top-5 要素具备明确物理意义」是不可证伪的主观判据 |
| P4 | §5.3 `_unitary_hilbert_lift` | 只输出 `[cosθ, sinθ]` 实振幅，定理中的相位 `e^{iφ}` 从未实现；`schmidt_weights` 可负、平方后符号丢失，不满足厄米可观测量读出 `Tr(ρO)` |
| P5 | §5.3 `peps_spatial_coupler` | 实际是一个普通 `Conv2d(32,96,3)`，「模拟 2D PEPS 面积律耦合」名不副实 |

### 4.5 验收判据自身

- **G1** Step 2「恒等重构误差 < 1e-6」：PixelUnshuffle/PixelShuffle 本身可逆，但加了 `radar_encoder`、`avg_pool2d`、`interpolate` 后不是恒等，判据无从满足。
- **G2** Step 2「显存降 ≥50%、吞吐提速 ≥2.2×」：忽略 `q` 长度 10201 的 cross-attention 与 4 步 ODE × 2 次 `velocity_net`（8 次大卷积），很可能不降反升。
- **G3** Step 1「QPE CSI@2.0 > 0.125」接近 Oracle 0.1653，且任务混淆。
- **G4** Step 4 要求改上游划分与评测器，等于与 38 个已注册实验不可比；蓝图未提供训练代码、算力预算与 paired per-seed 差值实现（§11.9 P4）。

## 6. 裁定与下一步

**研究建议：BLOCKED。** 三条理由：① 三族机制命中 §9 / §11.8.2 封口且无新机制证据；
② 数据契约与上游不可兼容（U/V 不存在、patch 尺寸、掩码评测）；
③ 核心模块的物理声称与实现脱节，且 CFM 无训练目标，无法产生可核验结果。
本结论按 ARIS 协议记为 `provisional`（同族审查），不得写成「已证明不可行」，
只写「在当前证据与上游规则下不予立项」。

**代码库：按用户要求构建**，展示名 `QLag-FlowNet`、代码标识 `QLFN`、主类 `QLagrangeFlowNet`，定位为可审计参考实现：

- 修 D2/S2/S4/S5/S6 的 shape 与契约问题，使**任意正整数 H/W** 经对称 padding
  后都可折叠/还原（不是「可被 3 整除」，见 `QLFN_SPEC.md` R3 修订）；
- 补 T1 的 CFM 训练目标；**不再宣称「修 T2」**（等价重写，见 §1.1），
  改为补 binary-mask 契约与全掩码回归测试；标注 T3/T4 的口径限制；
- 把 P1–P5 的物理声称降级为诊断量，docstring 中写明「非密度矩阵、非纠缠熵」；
  **诊断熵不得门控输出**（aihero Spec 轴最严重发现，已在 `model.py` 移除门控）；
