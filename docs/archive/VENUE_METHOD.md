## 1. 先说结论：Q-LagrangeFlow 蓝图不能作为立项依据

蓝图的三个模块，每一个都精确地落在上游已经做过实验、并且已经**结案舍弃**的方向上。这不是「还没试过」，而是「试过、有数字、有裁决、写进了舍弃清单」。按 `MASTER.md §11.8.2`，被证否等于停止派生，不是换个说法再试一次。

| 蓝图模块 | 上游对应的已封口方向 | 决定性证据 |
|---|---|---|
| M1 物理引导拉格朗日形变对齐（§4 / §5.2） | 显式运动 / 半拉格朗日平流 / 风漂移时滞对齐 | `E15-oracle-advection-ceiling.md:42-61`：完美 QPE + **不动** = 0.1653，任何平流都是负增益（0.1432 → 0.1303），每个 lead 都更低；`E16-four-tier-results.md:62-82`：门控 Lagrangian `full` 0.0266 / `res` 0.0704 / `qpe_0` 0.1000、**0/10 过地板 FAIL**；`FOUR_TIERS_PLAN.md:76-81`：`grid_sample(bilinear)` 不守恒，质量比 0.886–0.928；`MASTER.md:1085` 显式运动族整体舍弃 |
| M2 量子启发 Hilbert / PEPS 张量网络（§3 / §5.3） | 复数保真度注意力 / 复数干涉残差 / 二维张量网络空间编码 / E33 派生的相位对齐·拓扑约束 | `docs/radarNWP-QI-optimization.md:3-8`：**⛔ REJECTED / SEALED（E34 gate review）**，A/B/C/D 四方向零算力全部舍弃，根因即「把 E33 的 61% 排布效应读反了」；`MASTER.md:1083` 舍弃清单逐字列出「复数干涉残差块、二维张量网络空间编码，以及一切由 E33 派生的『相位对齐 / 拓扑约束』模块」；`MASTER.md:1177` 复数卷积表达力不超过实值卷积；`E02-quantum-coupling.md:36-44` Koopman 倾向耦合是**最确定的负面结果**（0.0122 vs 骨干 0.0384） |
| M3 频率解耦条件流匹配（§4 / §5.4） | 生成式 / 扩散 / 流匹配新架构 + 由 E33 派生的频域干预训练方案 | `MASTER.md:1085` 与 `E35:146-152`：GitHub 新架构族逐族比对后「没有任何新架构够格进『有真实可能成功』档」；`MASTER.md:791, 1053`：E32/E33 之后不再设计新的频域干预臂、不再派生训练方案；`MASTER.md:1170-1173`：归一化高频占比与分数**负相关**（−0.575 / −0.6374），去掉 96–99% 高频能量 2 mm 档只差 −0.000061 |

此外还有三处**数据前提错误**，不修就跑不起来，也不是换个 reshape 能补的：

1. 蓝图 §2.4 声称 NWP 27 通道含「850/700/500 hPa 的 U/V 风分量、垂直速度 W、TMP」。实际 `radar_nwp_bench/data/index.py:19-24` 的 27 个变量里只有 `WS500 / WS700 / WS925` 三个**风速标量**，**没有 U/V 矢量、没有风向**（`MASTER.md:1186`、`E37:43-46`）。因此 `Δx = v_wind · τ` 的形变场没有物理输入源，M1 的接口前提不成立。
2. 蓝图 §5.2 把 `x_radar_t0: (B, 10, H, W)` 当作「t₀ 单时刻 10 层体扫」。实际 `x_radar` 是 **11 个时间帧 × 10 个变量**，即 `(B, 11, 10, H, W)`（`models/base.py:12-14`）。这不是形状笔误，是把时间轴和变量轴读反了。
3. 蓝图 §1.1 用「61% 的结构性能赤字来自空间相位错配」作为立项动机。上游 `MASTER.md:1175, 1750-1753` 明确判定：这 61% 是**用真值替换高频段 + 等偏置配平的离线后处理**量出的**信息缺口**，不是可训练模块能补回的**优化缺口**；且打乱排布只 +0.000031（3 正 7 负）。`MASTER.md §10.1bis` 已把该结论标为「不可部署、不得写成任何可训练方法的依据」。

蓝图的验收目标 `CSI@2.0 ≥ 0.1250`（§7 Phase 4）也不可用作判据：`MASTER.md §11.9 P1` 规定单次峰值一律不作判据，基线 10 seed 只有 5/10、4/10 过地板，Fisher 单侧 p = 0.5，峰值端离散 9.59×。

**已接入的 26 个基线对蓝图的直接反证**：`artifacts/gate_review.md` 用可执行的资格门逐个审查了蓝图整体与三个模块，六条候选中五条 `REJECTED_AT_GATE_1`，唯一 `ELIGIBLE` 的是刻意构造的、完整报数四件套的对照组。`scripts/verify_integration.py` 把这条裁定固化成了回归测试。

## 3. 顶会重新定位

### 3.1 为什么不能继续「造新架构」

`MASTER.md §11.2` 给了两条准入原则：① 不造没有物理信息源的算子——若模块不引入新的观测量或可核验的因果先验，它只能在条件期望 `E[Y|X]` 内打转；② 单变量受控 + 真实通道参数配平。上游 38 个已注册尝试里，所有建设性路线（量子耦合、复杂 NWP 融合、软 FSS、拉格朗日平流、Z-R/幅度/分布标定、PMM、蒸发门控、单帧神经 QPE、集成、频域干预）的结果全部是**负面、中性、弱阳性或不可部署**。`MASTER.md:1738` 的结论是：「0.0924 与 0.1653 之间只有 0.0729 空间，建设性路线没有一条能稳定地走进去」。

继续往这个方向投算力，等于用一个新的架构名字去重复一个已经被 38 次实验封口的命题。审稿人只要看到 18 个 SOTA 全部低于一个 `np.repeat` 的基线，第一反应不会是「再试一个模型」，而是「这个 benchmark 的评测还能不能信」。

### 3.2 主线 A（推荐）：把负结果升级为可判定性方法学

**一句话叙事**：*不是我们没找到更好的模型，而是我们证明了在当前的样本量、阈值稀疏度与 seed 方差下，这个领域惯用的架构比较在统计上不可判定；并给出了使其可判定的最小证据协议与一个可迁移的诊断量。*

六个可写进论文正文的贡献：

| ID | 贡献 | 证据状态 |
|---|---|---|
| C1 | 统一的雷达+NWP 近预报基准：26 个基线、统一 seam、双口径评分、case 级划分、断帧鲁棒划分、完整复现包 | 已具备（`configs/baselines.json`、`artifacts/`） |
| C2 | 负结果主表：18 个已训练 SOTA 在 `CSI@2.0` 上**全部低于无参数持久性地板**；换 score-aware 损失让 18/18 抬升（中位 5.5×）却仍 0/18 超 0.10 | `RESULTS_FINAL.md:285-352` |
| C3 | Oracle–floor 分解：把性能瓶颈定位到 **QPE 反演的空间结构**而非外推；证明任何解析平流在此数据集上都是负增益，且 `grid_sample` 不守恒 | `E15`、`E16`、`FOUR_TIERS_PLAN.md:76-81` |
| C4 | **可判定性诊断量** `seed_range / headroom = 2.29`：给出「单次峰值不可判定」的量化判据，并证明两级配对 bootstrap（窗口 + 种子）才能把两臂分开 | `E13`、`MASTER.md §11.9`；`qmlbench/results.py:decidability()` 可执行 |
| C5 | 对「模糊导致塌陷」这一流行解释的**逐层证伪**：+0.950 相关只在标准损失总体成立、归一化后转负（−0.575 / −0.6374）；去 96–99% 高频只 −0.000061；E33 的 61% 是信息缺口而非优化缺口，打乱排布 +0.000031 | `E29`、`E31`、`E32`、`E33`、`MASTER.md §10.2` |
| C6 | 可执行的**证据准入协议**（§11.9 P1–P6 + §11.2 两条）作为社区可复用产物，含已封口方向索引与自动裁定 | `qmlbench/gate.py`、`artifacts/gate_review.md` |

C4 是把论文从「一个领域的负结果」抬到「AI 方法论」的那一步。C6 让审稿人能拿走一个工具，而不是一条抱怨。

**投稿排序**：NeurIPS Datasets & Benchmarks Track（最契合，负结果与评测协议有明确版面）→ ICML（若能补齐 X2 的跨数据集迁移证据）→ TMLR（明确接受 negative results，且不要求「novel method」）→ 备选 AAAI / AISTATS。CVPR main track 对这个题材最不友好：它偏好视觉生成与可展示的定性结果，而本文的结论恰恰是「别再看生成纹理了」。若坚持 CVPR，只能走 Workshop / benchmark 相关 track，不推荐作为首选。

### 3.3 支线 B：建设性路线的唯一合法入口

若仍要做「提出新方法」的论文，**唯一**满足 §11.2 ① 的路径是引入**新的观测信息源**——这是数据立项，不是模型立项：

| 新信息源 | 为什么能补 | 当前缺口 |
|---|---|---|
| 真实 U/V 风矢量（含 850/700 hPa 风向） | 让平流/形变有可核验的物理输入，而非用风速标量反推方向 | 27 变量只有 3 个风速标量（`data/index.py:19-24`） |
| 双偏振量 ZDR / KDP / ρhv | 直接约束雨滴谱与 QPE 反演，正是 C3 定位到的瓶颈环节 | 现有雷达 10 变量无偏振量 |
| 地面雨量站实时同化 | 把「瞬时反射率 → 6 分钟积分通量」的量纲鸿沟（r = +0.17）用独立观测补上 | 业务实时可得性上游明确标注「未证实」（`MASTER.md:63-67`） |
| 多站点 / 多季节 | 解除单站单季节限制，让结论可泛化 | 62 case 全部来自 BJ 一站、5–9 月（`README.md:973-974`） |

这条线必须在拿数据**之前**预注册 §11.9 全部判据（≥10 seed、同批次基线复现、ep00 绑定、四件套报数、两端差值门槛、增益落在可用空间内），并按 §11.2 ② 做单变量受控 + 真实通道参数配平。**在这四类数据到位之前，任何「新方法」论文都不该启动。**

### 3.4 支线 C：工具化

把资格门与基准包做成独立开源工具（证据协议 + 26 基线配置 + 两级 bootstrap + Oracle 解析臂），投 NeurIPS D&B 的 artifact track 或 TMLR / JOSS。这条可以与主线 A 合并提交，作为 reproducibility package，不必单独投稿。

## 4. 最小增量实验矩阵

> **范围声明**：本节是**待执行的工作计划**，不是本次交付的实现范围。`SPEC.md` §2 N2 明确界定 `qmlbench` 代码层「不训练、不评测、不跑 forward pass，只做元数据接入与证据协议」。X1/X2 所需的训练算力与外部数据须另行立项，本次不执行、不声明已执行。

主线 A 的现有证据已经足够撑起 C1–C3、C5、C6。**真正缺的是 C4 的普适性**：目前「2.29×」只在 BJ 这一个数据集上量到，审稿人完全可以说「那是你们数据太小」。X2 是唯一能把这条反驳挡回去的实验。

## 5. 论文骨架（按 NeurIPS D&B 8–9 页）

1. **Introduction**：以「18 个 SOTA 打不过一个 `np.repeat`」开场，立刻给出本文不是提出模型，而是回答「这个比较到底能不能判定」。
2. **Benchmark**：62 case、统一 seam、双口径评分、26 基线、case 级与断帧划分、数据审计（配准、有效时对齐、sentinel 解码、单位）。
3. **The floor and the ceiling**：0.0924 / 0.1653 / 0.0729；Oracle 的构造与特权信息边界；平流负增益与质量不守恒。
4. **Undecidability**（核心章）：2.29× 诊断量的定义、10 seed 通过率、Fisher p、两级配对 bootstrap；给出判据 `seed_range / headroom > 1 ⇒ 单次峰值不可判定`。X1/X2 结果放这里。
5. **Falsifying the blur narrative**：C5 的四层证据链，明确「信息缺口 ≠ 优化缺口」。
6. **The protocol**：§11.9 P1–P6 的形式化、可执行实现、已封口方向索引；用蓝图 Q-LagrangeFlow 作为**案例**展示协议如何零算力否决一个看似漂亮的方法（这是很有说服力的一节，且不点名外部来源）。
7. **Limitations**：单站单季节、阈值稀疏、Oracle 用真值、评测端确定性而训练端不确定、外部数据集只验证到 X2 的范围。
8. **Artifacts & reproducibility**：26 基线配置、seed 清单、全部评测 JSON、两级 bootstrap 代码、资格门。

## 6. 风险与应对

| 风险 | 严重度 | 应对 |
|---|---|---|
| 「只是你们数据集太小」 | **致命** | X2 跨数据集复现。做不到就把目标降到领域刊（IEEE TGRS / GRL / Environ. Data Sci.），不要硬投 AI 顶会 |
| 负结果被判为 incremental / 缺乏 novelty | 高 | 把 C4 + C6 放在最前，而不是把 C2 放在最前；标题用「undecidability / evidence protocol」，不用「we benchmark 18 models」 |
